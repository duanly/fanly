# 平台共享图标库

h5 和 admin 两个前端共用这一份 SVG 图标。从 [iconfont](https://www.iconfont.cn)
下载 SVG 后，**直接放进这个 `icons/` 目录即可**——不分子目录、所有图标共享，
后台「选择图标」弹窗里会自动出现，无需改代码、无需注册。

## 命名

文件名全小写、单词用连字符，即图标名。例如：

- `coffee.svg` → 引用名 `coffee`
- `milk-tea.svg` → 引用名 `milk-tea`

数据库里存的时候带 `icon:` 前缀，例如 `icon:coffee`。

## 从 iconfont 下载

1. iconfont 选好图标 → 「下载素材」→ 选 **SVG**
2. 文件名改成英文小写短横线，直接丢进本目录

## 颜色

单色、多色 SVG 都支持：

- 文件始终保留原始颜色——多色图标在白底页面/后台选择器里就是彩色的
- 同一个图标放到首页彩色渐变宫格时，由调用处传 `color="#fff"` 局部压白，
  不需要准备两个文件

## 尺寸

图标统一按正方形 `viewBox`（如 `0 0 24 24`）绘制，
组件用 `size` 属性控制实际像素（默认 24）。

> 注意：扁平目录下文件名不要重复；同名文件会被后者覆盖。
